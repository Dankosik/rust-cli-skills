# Rust CLI Skills 1.0.1 — Unreleased

Prepared instruction corrections for the existing 16 independent Rust CLI skills.
This document is a candidate release note, not a publication announcement.

Activation is more decision-specific; reviews and diagnoses no longer imply
editing, and implementation continues through applicable checks and repairs.
Evidence follows the changed type, byte, process, filesystem, platform, or
resource contract rather than every topic named in a skill. Rust ownership and
safety distinctions are retained. An agreed change does not reopen unrelated
technical choices.

CLI-specific prompts, an instruction audit, 20 behavioral evaluation
specifications, and a comparison-results template accompany the revision.
Behavioral model comparisons have not been run; structural validation alone
cannot establish better model behavior or faster generated programs. Record
focused behavioral evidence before publishing this semantic update.

Names, paths, independent installation, required environments, CI, and packaging
are unchanged. The candidate is a PATCH correction within those contracts.
Published examples still use [v1.0.0](https://github.com/Dankosik/rust-cli-skills/releases/tag/v1.0.0).
No new tag, release assets, marketplace update, or provider approval is implied.

The audit and evaluation documents are authoring-only materials in the source
repository, not runtime dependencies of installed skills or a bundled test runner.
