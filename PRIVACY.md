# Privacy

This package contains static skill instructions, metadata, and visual assets.
It includes no MCP server, account integration, lifecycle hook, analytics client,
or publisher-operated data endpoint. Installing it does not create an account
with Dankosik or grant additional access to your files or services.

Your chosen AI host processes prompts and may use its tools according to that
host's settings, permissions, and privacy terms. GitHub and installation tools
may process download requests under their own policies. This package does not
replace those policies.

Support is available through [GitHub issues](https://github.com/Dankosik/rust-cli-skills/issues).
Do not post secrets or private source code in a public issue.

Published by [Dankosik](https://github.com/Dankosik).
