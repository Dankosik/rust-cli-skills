# Support

Report installation problems, inaccurate instructions, and compatibility issues
through [GitHub issues](https://github.com/Dankosik/rust-cli-skills/issues). Include the package version,
client/installer version, command, and a redacted reproduction. Do not include
credentials or confidential files.

This is a community-maintained open-source package under [MIT](LICENSE).
No response-time or support-service commitment is included.
